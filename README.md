# Yash Marketing - Delivery & Payment OS

Dedicated operational web app for Yash Marketing field staff and delivery personnel.

## Key Features
- **Delivery / Delivered Tab**: Live queue of dispatched/out-for-delivery orders. 1-tap "Mark Delivered" updating Stage 8 in Yash Marketing backend.
- **Payment Collection Tab**: Cash and Online (UPI/QR) payment collection with photo proof upload linked directly to the dealer's order.
- **Delivery & Collection History**: Daily record of all completed deliveries and collected payments.
- **Zero-Storage Online Workflow**: 100% cloud-managed via GitHub REST API.
